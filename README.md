# Практична робота №2. Патерн «Спостерігач» (Observer)

## Тема та мета

Реалізувати патерн Спостерігач мовою C++ у системі Розумний дім і показати, як пристрої підписуються на зміни клімату центрального хаба. Патерн утворює зв'язок один до багатьох: один суб'єкт сповіщає всіх зареєстрованих спостерігачів, коли змінюється його стан.

## Класи програми

- `IObserver` — інтерфейс спостерігача з методом `Update(float temperature)`.
- `ISubject` — інтерфейс суб'єкта з методами `Attach`, `Detach` і `Notify`.
- `SensorHub` — центральний хаб; зберігає температуру та список спостерігачів, а після `SetTemperature` викликає `Notify`.
- `AirConditioner` — вмикає кондиціонер, якщо температура вища за 25 °C, інакше вимикає його.
- `SmartDisplay` — показує отримане значення температури.
- `main()` — створює об'єкти, підписує пристрої, змінює температуру, відписує дисплей і підписує його знову.

```text
              ISubject
                  ▲
              SensorHub ─────── Notify() ─────┐
                                               │
              IObserver                        │
               ▲       ▲                       │
               │       │                       │
      AirConditioner  SmartDisplay ◄───────────┘
```

## Демонстраційний сценарій

1. `SmartDisplay` та `AirConditioner` підписуються через `Attach`.
2. При 22 °C дисплей показує значення, а кондиціонер вимкнений.
3. При 28 °C дисплей показує значення, а кондиціонер вмикається.
4. Після `Detach` дисплей не отримує оновлення.
5. Після повторного `Attach` дисплей знову отримує зміни.

Хаб працює з пристроями через `IObserver`, тому йому не потрібно знати конкретні типи підписників. Це зменшує зв'язаність класів. У прикладі підписниками є об'єкти, створені в `main()`, а `SensorHub` зберігає на них невласницькі вказівники; об'єкти мають жити довше за час підписки.



## Висновок

Реалізовано систему Розумний дім із класами `IObserver`, `ISubject`, `SensorHub`, `AirConditioner` та `SmartDisplay`. Зміна температури автоматично сповіщає підписані пристрої, а `Attach` і `Detach` дають змогу керувати підписками під час виконання програми.
