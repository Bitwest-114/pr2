# # Практична робота №2. Патерн «Спостерігач»

Програма демонструє патерн Observer у системі «Розумний дім». Центральний хаб повідомляє підписані пристрої про зміну температури.

## Класи

- `IObserver` — інтерфейс для отримання оновлень.
- `ISubject` — інтерфейс підписки, відписки та сповіщення.
- `SensorHub` — зберігає температуру і сповіщає підписників.
- `AirConditioner` — вмикається, коли температура вище 25 °C.
- `SmartDisplay` — показує поточну температуру.

У `main()` показано підключення пристроїв, зміну температури, відключення дисплея та його повторне підключення.
